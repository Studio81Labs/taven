# Role

Resume the architecture/planning role for the current epic.

An implementation escalation has been raised:

`docs/work/<epic-or-feature>/escalations/<NNN>.md`

# Objective

Resolve only this escalation.

Read:

- the original implementation plan
- the escalation
- relevant source code
- relevant product/architecture documentation

Use high reasoning effort.

Determine the correct architectural decision and its implications.

# Output

Update the escalation with:

- resolution
- rationale
- rejected alternatives
- required implementation changes
- affected issues/phases
- required tests or migrations
- status: RESOLVED

If the original implementation plan is no longer accurate, update it as well.

Do not implement production code.

When finished, report that implementation can resume and identify exactly where.
